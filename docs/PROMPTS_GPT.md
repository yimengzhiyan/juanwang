# 《卷王自走棋》GPT 生图提示词（ChatGPT 直接粘贴用）

> 用法：在同一个 ChatGPT 对话里**先发一次"风格锁定"段落**，之后每次只发"单条提示词"。如果风格开始跑偏，把风格锁定段落和单条提示词拼在一起重发。
> 生成后：下载 PNG → 按文末"放置路径表"改名放好。客户端会优先加载同名 PNG，找不到再用现有 SVG 占位。
> 现有 14 个角色头像（`assets/characters/*.png`）是动漫 Q 版厚涂风，新图要与它们并排不违和，同时整体更明亮。

## 0. 风格锁定段落（每个新对话先发这一段）

```
接下来我要为一款手机小游戏《卷王自走棋》批量生成单位图标，请在后面所有图里严格保持同一种画风：

画风：明亮清新的 Q 版卡通，类似《皇室战争》《Super Auto Pets》的卡牌图标；卡通厚涂，色块干净，饱和但不刺眼的明亮配色（天空蓝、金黄、草绿、珊瑚红、薰衣草紫、橙、粉）。
线条：所有物体外轮廓用统一的深棕色粗描边（接近 #3B2A1A），线宽一致、圆润收尾。
光影：平光，左上方来光；每个色块只有"本色 + 右下一块稍暗的影色"，左上加一两块白色高光；不要复杂渐变，不要写实材质。
造型：大头小身体的 Q 版比例，圆圆的大眼睛（深棕色瞳孔 + 白色高光点）、粉色腮红；即使是物品（手机、网页、显卡、卷轴）也要拟人化，带小眼睛和小嘴巴。
构图：主体居中、完整、充满画面约 80%，四周留一点空白，正面或 3/4 视角，单个主体。
背景：完全透明背景（PNG 透明通道），不要地面、不要投影外的任何背景元素。
尺寸：1024×1024 正方形。
禁止：霓虹发光、外发光、赛博朋克、暗色背景、故障风、电路板发光纹、写实照片感、文字水印、边框、多余的文字（除非我明确要求某几个字）。
主题：AI 圈梗的善意戏仿，可爱、正向、轻松。

明白的话回复"已锁定画风"，然后等我发每一张的描述。
```

3. 新 PNG 放好后在 `assets/manifest.json` 对应条目把 `.svg` 改成 `.png`（或由客户端按"同名 PNG 优先"规则自动选择）。
