# 《大玩家》GPT 生图提示词（ChatGPT / gpt-image 专用）

GPT 生图和 Midjourney 不同：**用完整的自然语言句子描述，不需要负面词语法，不要权重符号**；它能直接出**透明背景 PNG**，中文文字也基本能写对。本文件全部是可以直接粘贴到 ChatGPT 的中文段落。

## 操作流程（很重要，决定 14 张图风格是否统一）

1. **在同一个 ChatGPT 对话里生成全部角色**，不要开新对话。
2. 第一步先粘贴下面的「风格锁定」段落，再附上 `docs/reference/characters_sheet.png`（当前占位头像的合集图）作为参考图，让 GPT 先确认理解。
3. 然后逐个粘贴角色提示词。从第 2 个角色起，提示词开头已经写了"与上一张完全相同的画风"，GPT 会保持一致。
4. 每张图生成后检查：头在正中、脸占画面约 45%、四周有留白、背景透明。不满意就回复"保持画风不变，只把 XX 改成 YY，重新生成"。
5. 下载 PNG，按文末表格改名放入目录，刷新网页即生效（png 优先于 svg）。

**尺寸选择**：角色 / 建筑 / 骰子 / 棋盘背景选 **1024×1024（方形）**；Logo 选 **1536×1024（横版）**。

## 0. 风格锁定（第一条消息，和参考图一起发）

```
接下来我要为一款网页游戏生成一整套角色头像，请你严格统一画风。画风要求：高清日系动漫插画，Q 版二头身比例，大而有神的眼睛，圆润可爱的造型，干净利落的深紫色描边线条，柔和的赛璐璐上色带轻微渐变，整体带有明亮的赛博科技感，角色边缘有青色和品红色的霓虹边缘光，高光细腻。构图统一为头肩半身像，正面略微侧身，头部在画面正中，脸部约占画面 45%，四周留出至少 8% 的空白。输出透明背景的 PNG，1024×1024。不要写实风格，不要照片质感，不要 3D 渲染，不要任何文字、水印、商标或 logo，背景不要有任何元素。

我附上了一张当前占位头像的合集图，请参考它的构图、可爱程度和配色氛围，但画质和细节要远高于它。先回复"明白"，不用出图，等我逐个给角色描述。
```

## 6. 放置路径

| 素材 | 放到 | 备注 |
|---|---|---|
| 角色 ×14 | `client/public/assets/characters/<id>.png` | id 见各条标题，小写下划线 |
| 建筑 ×6 | `client/public/assets/buildings/empty.png`、`lv1.png` … `lv5.png` | |
| 骰子 ×4 | `client/public/assets/dice/h100.png`、`furnace.png`、`mahjong.png`、`vram.png` | |
| 棋盘背景 | `client/public/assets/board_bg.png` | |
| Logo | `client/public/assets/logo.png` | |

放好后：开发模式刷新页面即可；生产模式重新执行 `npm run build` 再启动。
单张 PNG 建议压到 1.5MB 以下（tinypng.com），不然手机首屏加载慢。
