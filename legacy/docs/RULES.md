# 《大玩家》玩法说明

> 扮演 AI 圈名人或模型娘，买下 AI 公司，升级成旗舰模型，向路过的对手收 Token，把别人熬到破产就赢。

## 开局
- 2~6 人（可加机器人），每人起始 **1500T**（Token）。房主可调起始资金、回合上限（默认 30 轮）和每步限时（默认 45 秒，超时自动操作）。
- 手机扫码进房间，选一个角色就能开玩。

## 你的回合
1. **用道具**（可选，可连用多个）→ 点 **掷骰子**（两颗 GPU 骰子）。
2. 棋子逐格前进，**经过融资轮 +200T**。踩到"宕机路障"会立刻停下。
3. 看落在哪：
   - **无主的基建 / 算力中心 / 电力数据站**：可以买，也可以不买（不拍卖）。
   - **自己的基建**：可花升级费升 1 级：v1 → v2 → v3 → v4 → **旗舰 (AGI)**。不需要集齐同色。
   - **别人的基建**：自动支付 **API 调用费**。集齐同色组的空地费用翻倍；被抵押的不收费。
   - **算力中心**：对方拥有 1/2/3/4 座，分别收 25/50/100/200T。
   - **电力 / 数据**：收骰子点数 ×4（对方两座都有则 ×10）。
   - **热搜 / 突发**：抽一张卡，可能发钱、扣钱、送道具，也可能引发全场事件（价格战、显存涨价、泡沫破裂……）。
   - **API 账单 / 显卡税**：交 200T / 100T 进奖池。**开源节**：拿走奖池全部 Token！
   - **被监管**：直接进监管审查（10 号格）。
4. 掷出 **双骰** 再掷一次；连续 3 次双骰直接进监管审查。

## 监管审查
- 下回合可以：付 50T 出来 / 用合规豁免卡 / 掷骰尝试出双骰。第 3 回合还没出来就强制付 50T。
- 只是走到 10 号格 = 路过参观，没事。

## 道具（来自热搜和突发卡，最多持有 6 个，回合开始时使用）
| 道具 | 效果 |
|---|---|
| 宕机路障 | 放在前方 1~8 格，谁走到谁停下 |
| DDoS 导弹 | 炸掉前方 1~10 格内一块对手基建的 1 级 |
| 火箭加速 | 本回合点数 +6 |
| 限流乌龟 | 指定对手下次掷骰只能是 1 |
| 防火墙护盾 | 免掉下一次 API 调用费 |
| 跳板机 | 传送到自己任意一块基建 |
| 合规豁免卡 | 监管审查中立刻出来 |

## 缺钱怎么办
- 回合开始时可把基建 **抵押** 给投资人拿半价，赎回要付 110%。
- 付不起账时系统会自动卖建筑（半价）、抵押基建；还不够就 **破产**，资产全归债主。

## 胜负
- 只剩一人没破产 → 胜利。
- 到达回合上限 → 比 **身价**（现金 + 基建 + 建筑投入，抵押按半价），最高者胜。
